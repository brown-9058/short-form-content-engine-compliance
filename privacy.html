Privacy Policy

This policy describes Short Form Content Engine, a privately operated, single-user local creator tool. Contact: ethan@ibrowns.com.

YouTube API Services

The application uses YouTube API Services, specifically the official YouTube Data API v3. See Google's Privacy Policy, YouTube Terms of Service, YouTube API Services Terms and Developer Policies.

Data accessed

Authorized requests access channel ID, title and uploads-playlist ID; video ID; title, description, tags, category and language; audience and synthetic-media settings; privacy, scheduled and published timestamps; upload and processing status; and owner file size for explicit recovery. Channel inventory is read for release-conflict checks. No email, Drive data, comments, viewing history or YouTube Analytics data is accessed by this implementation.

OAuth credentials

Authorization uses Google OAuth. Google passwords are never collected. Access and refresh credentials stay on the user's computer. Native macOS Keychain is preferred; permission-restricted local files are an explicit fallback. Each channel has separate local authorization and its ID and title must verify before use. Google's project-wide revocation can also affect other grants for the same Google account/project.

Purpose

Data is used only to verify the destination channel, upload exact human-approved and Community Guidelines-certified content, verify metadata and processing, prevent duplicate uploads, and schedule or publish after audit clearance. Original research, scripts, media, rights records, approvals, certification and publishing intent are generated independently of the API.

Sharing and sale

API Data is not sold, shared with advertisers or used for advertising profiling. Google and YouTube receive requests required to provide the API service. Local records are available only to the user and their expressly authorized agents. This website has no analytics, cookies, tracking, forms, embedded player or external JavaScript.

Retention and deletion

Remote observations and identifiers expire after 29 days without a verified refresh. Local deletion-only maintenance runs hourly when installed; ordinary CLI use also checks expiry. Installation is required before claiming local audit readiness. When the computer is off, maintenance resumes at login; it must not be used to archive expired API Data. Authentication failures prevent further use and remove affected snapshots; credentials expire locally if channel authorization cannot be verified within that window. Requested deletion runs immediately, including when remote revocation fails. Storage failures are reported for correction, not hidden.

Refresh replaces API observations rather than extending the life of old snapshots. Deletion preserves local original media and non-API upload-intent tombstones that continue preventing duplicates. Credentials and resumable session capabilities are deleted on disconnect. The developer's OAuth client configuration is retained. User-made exports, backups and historical diagnostic copies must also be deleted within the same period; they are not permanent archives.

Revoke authorization and delete local data

In the application's CLI, run python -m shortform youtube disconnect CHANNEL --revoke --delete-authorized-data --confirm CHANNEL, using the channel route unlikely-truths or company-logic. Use --dry-run first to preview. Omitting --revoke permits local deletion when you cannot contact Google; the Google grant may remain active. Failure to revoke or delete is reported separately.

You may also revoke access in Google Account permissions, then run the application's disconnect command for local deletion. Deleting local authorization or API Data does not delete already uploaded videos. Delete those separately using YouTube's own controls.

Policy changes

If access, collection or use changes beyond this policy, renewed acceptance is required before that new use. This application currently has no multi-user service.
