Obtain the official YouTube logo (not “Developed with YouTube”) from https://www.youtube.com/howyoutubeworks/resources/brand-resources/ linked by https://developers.google.com/youtube/terms/branding-guidelines . Read the current logo rules. Save the unmodified official PNG as youtube-logo.png. Use the official asset's clearspace/minimum-size rules; do not redraw, recolor or substitute it. Then run the build script. The integration remains useful without YouTube, so the integration uses the ordinary YouTube logo, separately from the application name. The build creates a clickable YouTube link at 120px width on white; inspect the actual official asset's clearspace before submission.
