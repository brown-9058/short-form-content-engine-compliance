Short Form Content Engine is a desktop workflow for creating, reviewing, managing and distributing short-form educational video content.

Research, writing, narration, graphics and rights records are prepared locally. Approved videos can then be prepared for supported distribution platforms using official APIs. Creators retain final review and approval responsibilities required by each platform.

This is a private creator workflow, not a generally available application or hosted service. This website provides public product and compliance information; it does not provide downloads, account sign-in or video uploads. TikTok production approval is not claimed.

TikTok integration

The desktop integration is designed to let an authorized creator send a selected, internally approved video to TikTok as an inbox draft. TikTok Login Kit handles consent; Content Posting API draft upload handles delivery. The creator completes final review, edits, disclosures and publication inside TikTok.

Direct Post is not enabled. There is no automatic public TikTok publication.

Official YouTube API integration

The publishing component uses the official YouTube Data API v3. Research, writing, narration, graphics, rights tracking and human review are independent local production features.

YouTube is the source of API channel identity and remote video information. Uploading requires exact human approval and separate Community Guidelines certification. Public publishing and scheduling remain disabled pending documented API-project audit clearance.

Google OAuth consent verifies the destination channel. Credentials stay local. You may revoke authorization and delete locally stored API Data. This does not delete videos on YouTube.
